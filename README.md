## Description

This repo is a blueprint/template for other repos I use. Common simple patterns
and files are present.

## Quickstart

1. create a new repo using this one as template
2. remove `*.lock` from `.gitignore`
3. change details where needed (don't forget the license)
4. commit normally and use
   [python-makefile](https://github.com/frnmst/python-makefile) for standard
   operations
